# Retroactive back-port waivers -- read by scripts/drift-audit.py.  Ruling R-ab, 2026-08-26.
#
# WHY THIS FILE EXISTS
# --------------------
# AGENTS.md rule 3 says a master commit that must not propagate declares it IN THE COMMIT:
#
#     Backport-not-needed: touches only the 1.21.11 toolchain pin
#
# and that the opt-out "lives in the commit that made the decision and cannot be applied
# retroactively to one somebody merely forgot".  That is the right rule and it stays.
#
# The 26.x conversion broke it, once, at scale.  Eleven master-only commits rename master from
# yarn to official Minecraft names, pin the 26.2 toolchain, or repair the suite for it.  Applying
# any of them to a yarn band would break that band -- they are un-propagatable BY CONSTRUCTION --
# and every one of them was committed without the trailer.  Six are already on origin/master, so
# rewriting them is off the table regardless of what the rule says.
#
# So gate 7 failed on EVERY run, forever, for a reason no amount of work could clear.  That is not
# a cosmetic problem: the TWELFTH missing commit -- a genuine forgotten back-port, the exact defect
# this auditor exists to catch -- reads identically to the eleven.  A permanently red gate detects
# nothing, because nobody reads it.
#
# WHY THIS IS NOT A HOLE IN RULE 3
# --------------------------------
# An escape hatch anyone can extend tomorrow repeals the rule it excepts.  This one cannot be:
#
#     A waiver whose commit is NOT AN ANCESTOR OF THE `cutoff:` SHA BELOW IS REFUSED (exit 2).
#
# Tomorrow's commit is not an ancestor of a frozen cutoff, so it cannot be waived here -- the
# trailer remains the only opt-out for anything new.  Widening the exception means MOVING the
# cutoff, which is one line in a diff, in a commit, with a reason: reviewable, which a quietly
# growing list of shas is not.  Do not move it to make a red gate go green.
#
# The auditor also fails closed on: a missing or duplicated cutoff, a sha that is not 7-40 hex, a
# sha that resolves to no commit or is ambiguous, an empty reason -- and it reports a waiver that
# has stopped matching anything as STALE (exit 1), so this file cannot rot into credit for nothing.
#
# FORMAT
# ------
#     cutoff: <sha>            exactly one, required whenever any entry follows
#     <sha>  <reason>          reason non-empty; everything after the sha is the reason
#     # ...                    comment; blank lines ignored
#
# ASCII only.  Every line here prints on the drift-REPORTING path, and a Windows cp1252 console
# cannot encode anything else -- see the note at the top of drift-audit.py.
